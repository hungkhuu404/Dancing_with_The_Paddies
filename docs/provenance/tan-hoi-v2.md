# Tân Hội v2 pixel export provenance

The active web bundle is CONTRACT-001 2.0.0. Its 20 NISAR acquisitions and 2,344 cells use the 75% pixel rule and asymmetric 50% temporal guard. Selection used DSWx-S1 after the original H3 freeze; the comparison is post-hoc, not independent validation or ground truth.

S1–S5 input snapshot: cube SHA-256 `0a7949591fd17dd8ee83665d4e14247a2c225c1bff136a0c999ebcd58e5f217f`; metrics SHA-256 `2be917c3e99f1c5fd2ba369eb41be30f6df378e330860b35d50fae609b0f9ba2`. The BANG-2 landcover table used in S7 has SHA-256 `47106610fda1f5b677e53eeb2788baf41bd4cce6efc1500aff508d422902e36f`. S7 regenerated cells, series, summary and metadata with the existing OSM boundary and all 24 real published hamlet points. Sites, AOI, places and 20 radar backdrops are byte-identical to the previous public bundle. No fixture points are used.

`validation.json` is Bằng's S6 pixel comparison, copied from the supplied archive SHA-256 `998892234f728b8926f5e21dc2ae8bc61d68bdfb5bc8a30dd6e0cbcc4780fc44`. Its `filtered` block describes the pixel method; `posthoc.PH-01.before` retains the H3 comparison as historical context, not as pixel output. The 1,275 NISAR `yes` cells reported there equal the v2 summary's 7,968.75 ha / 6.25 ha. This aggregate check alone does not prove identity of every S6 input; the comparison handoff does not provide an input snapshot hash, so exact input identity remains to be confirmed by Bằng.

The Method and limits page incorporates the relevant cautions from Bằng's BANG-8 limits draft: sparse observations do not prove continuous flooding, and trees and buildings can mask water. The BANG-8 draft also mentions two requested additional NISAR acquisitions; they are not included without catalog confirmation and a consistent new run. BANG-9 is a separate Bang Rakam DSWx reference grid and is not mixed into Tân Hội data.

Two freeze timestamps have different meanings: `validation.json`'s `frozen_utc` (`2026-11-13T06:23:57.749213Z`) is the original H3 pre-DSWx baseline; `meta.json`'s `method.frozen_utc` (`2026-11-14T07:33:39.501370Z`) is the subsequent pixel snapshot. Neither converts pixel selection into an independent test. The original H3 public data remains accessible in Git history, not as active web data. Additional NISAR acquisitions beyond this 20-image snapshot are not asserted absent; they need catalog confirmation and a new aligned export and comparison.
